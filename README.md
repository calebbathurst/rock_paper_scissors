# Soul Redemption: Rock Paper Scissors
My original college game — challenge the Devil at Rock Paper Scissors to redeem your soul.
## Play it
Open `index.html` in a browser.
## Built with
- HTML, CSS and JavaScript
- Foundation, GSAP, SVG and Vue
## Background
Built in 2020 in my final semester of Durham College's Contemporary Web Design program. One of the projects on my portfolio at https://www.bathurstwebsolutions.ca/
